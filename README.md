Руководство пользователя:



Это обычные крестики-нолики на двоих.


Ваша задача — поставить три своих значка (X или O) в один ряд: по горизонтали, вертикали или диагонали. Играем на стандартном поле 3x3.
Первым всегда ходит игрок с крестиками (X). Чтобы сходить, просто кликаете левой кнопкой мыши по любой пустой клетке. 

 
 
 
 
 
 Интерфейс и процесс игры:
  При запуске программы поле пустое, игра ждет вашего хода.
  Как я и говорил, первым ходит "X". Сверху написано, чей сейчас ход.
